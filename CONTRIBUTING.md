# Contributing

Thank you for your interest. Bug reports, questions and feature requests are
welcome as GitHub issues.

Pull requests are not accepted. The software is distributed under a
noncommercial license and is also offered under commercial terms, so taking
outside code would require a contributor license agreement that is not in
place. A fix you describe in an issue may be re-implemented by the maintainer.

When filing an issue, please include the operating system, GPU, driver and
CUDA versions, the exact command line, and the error output or a minimal
reproduction.
